# Videos для інтерактивного формату

Кожен персонаж потребує 3 відеофайли. Шлях:
`public/videos/{characterId}/{intro|positive|negative}.mp4`

## Конвенція

| Файл | Коли програється | Що показує |
|---|---|---|
| `intro.mp4` | На старті сценарію | Перша репліка персонажа (firstLine з `lib/characters.ts`). Має закінчитись — після `onended` зʼявляться 2 кнопки вибору. |
| `positive.mp4` | Якщо користувач обрав ліву (зелену) кнопку | Реакція персонажа на тепле/щире продовження розмови. |
| `negative.mp4` | Якщо користувач обрав праву (червону) кнопку | Реакція персонажа на провокативний/неввічливий вибір. |

## Персонажі

```
public/videos/linda/intro.mp4
public/videos/linda/positive.mp4
public/videos/linda/negative.mp4

public/videos/mark/intro.mp4
public/videos/mark/positive.mp4
public/videos/mark/negative.mp4
```

## Технічні рекомендації

- Формат: `mp4` (H.264 + AAC), щоб працювало в Safari/iOS без додаткового кодеку.
- Aspect ratio: 16:9 (компонент рендерить `aspect-video`).
- Розмір: бажано до 5-10 МБ на кліп, інакше повільне завантаження.
- Без звуку АБО зі звуком — будь-який варіант працює (`<video>` без `muted`).

## Поведінка без відео

Якщо файлу немає, `<video>` тригерить `onError` → компонент `InteractiveScene` рендерить анімований текстовий fallback з аватаркою і репліки із `characters.ts`. Тобто додавати відео можна по одному, інші екрани не зламаються.
